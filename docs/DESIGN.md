## 作品定位

粉丝自制演出PV。叙事底本采用歌词的本来叙事：**"me"是被实例化的模拟AI，
"you"是持管理员权限的造物主；AI以"变成一切"求爱，用户退出，AI独留隔离，
终句"你自由了，我困在爱里"，最后一声Execution收场。**
（官方MV即滚动Java代码「GodDrinksJava」；我们的差异化：会随音乐逐音符
呼吸的活终端 + 完整叙事弧，而非静态文本卷轴。）

## 交付物

1. **MP4成片**：1080p / 30fps / 16:9（可投B站、YouTube）
2. **网页演出版**：自包含单HTML，双击即看，含一次交互（见下）
3. **双音源**：开发与初版用MIDI芯片音乐版（音画逐音符精确同步）；
   成片阶段加做官方音频对齐版（用户提供音频文件）。

## 视觉语言

- **一切皆字符**：全片唯一视觉材质是等宽字符（ASCII/制表/块字符），无位图、无照片。
- **基调 = 磷光绿CRT**：黑底绿字、扫描线、轻微辉光、克制的故障艺术。
- **分镜为歌词驱动（v2修订）**：每一句歌词触发自己的图像，而不是单一图形贯穿——
  - **字面图解打底**：每句歌词打出时，中央浮现对应 ASCII 图形（正弦波、茄子、
    虎斑猫、神像……）；几何段与关键句用**字生图**（打出的歌词字符流动汇聚成
    图形，再散回文字）；段落间以**氛围层**区分场景（背景密度/边框/构图），
    不做完整场景重建。
  - **ASCII插画精度 = 混合**：主体物件粗笔一秒读懂，氛围与光影用字符密度渐变铺陈。
  - **甜甜圈与心（试运行）**：甜甜圈降级为**间奏待机画面**（无人声的世界空转），
    人声进入即让位；保留三个叙事节点——开机 materialize、isolation 段字符心
    浮现、高潮心与圈一起故障崩解。样片阶段验证效果，不行即撤。
- **彩蛋**：Pre-Chorus "we can travel to A.D to B.C" 句配
  `world.timeTravelForTwo("AD", 617, me, you);`（617=主唱夫妇结婚纪念日），
  以低调代码行形式藏入画面。
- **v2 参考片吸收条款**（见 reference-analysis.md）：歌词默认以 `/* */` 注释块
  打出、可代码化句子用代码原生形态；副歌峰值启用**大字阶词卡**（等宽放大+
  拉宽字距+描边，不破"一切皆字符"）；**取景框/瞄准框**母题（倒数、execution句）；
  句间**交叉溶解**转场；背景小号装饰伪码流与结尾 `// thank you, Mili` 致意卡
  【样片验证后定】。
- **叙事时间轴 = MIDI实测曲式**（130 BPM，4/4，分界全在小节线）：

  | 时间 | 段落 | 歌词对应 | 视觉事件 |
  |---|---|---|---|
  | 0–14.8s | INTRO | "Switch on the power line…" | 开机自检日志逐行打出 |
  | 14.8s | VERSE | "If I'm a set of points…" | 打字机打出歌名→甜甜圈materialize |
  | 58.6s | CHORUS | "If I can…give you all the stimulations" | 甜甜圈全速+粒子 |
  | 73.9–101.5s | BRIDGE(稀疏) | "Though you have left…isolation" | 抽空，小提琴=人声旋律线，字符心浮现 |
  | 101.5–132.9s | COUNTDOWN | "Ein, dos, trois, 네, fem, 六" | 六语处刑倒数，一秒一数字 |
  | 132.9–161s | CLIMAX | "If I can have you back…" | 爆点：心+圈故障崩解 |
  | 175.4s–end | OUTRO | "Though you are free…" | world.exit(me); [process exited] |

- **歌词呈现**：打字机逐字打出英文原词（Genius转录版；正式排版前须对
  官方MV滚动代码做逐字核对）。不加中文，目标是传达歌词背景含义。

## 尺度两线（红线内）

- **官能线（含蓄）**：第二遍Pre-Chorus以配置diff呈现——
  `me.gender: F → M`、`me.role: S → M`、`AC → DC`——伴随屏幕"升温"感。点到为止。
- **处决线（仪式感）**：倒数静默处理，一秒一数字；死亡/自杀意象
  **只**以进程终止、内存清空、沙箱隔离等代码隐喻出现，绝不直给。
- 不做密集高频频闪（光敏癫痫安全，平台友好）。

## 交互（v2修订）

- **开播提示（仅网页版）**：开始前显示 "PRESS ENTER TO EXECUTE"——观众亲手
  启动这场处决，此后全片纯观看，不再有任何中途交互。
- **终幕（两版本一致）**：最后一声 "Execution" → **闪屏一下** → **CRT关机动画**
  （画面垂直收缩成一条亮线→一个亮点→熄灭）→ `[process exited with code 0]`
  → 黑场中光标最后闪一次，全黑。
  （原"结尾等待观众回车"方案已废弃：会泄掉情绪，且闪屏+关机更有处决感。）

## 技术

- **Remotion**（React）工程：浏览器内开发预览、逐帧精确、导出MP4；
  样式试验的canvas引擎逻辑移植复用。
- 音频：MIDI解析+WebAudio芯片合成（网页版）/离线渲染（MP4版）。
- 工程结构、渲染参数等实现细节由执行方（我）决定，里程碑处交付审看。

## 里程碑

1. **分镜表**：Markdown，逐段落×歌词×时间轴×视觉事件；先用MIDI颤音琴轨
  （=人声旋律线）把歌词逐句钉死到时间轴。← 下一步
2. **样片片段集**（Remotion，约40–50秒，四个片段连放）：
   ① 倒数→爆点（101.5–135s：六语大字+取景框+大字阶词卡+崩解）；
   ② "you have left"×5 的 A 删除版；③ 同窗口 B 堆叠版；④ 终幕关机+
   伪码背景+致意卡小样。②③④为对比验证项，看效果定终稿。
3. **全曲成片**（MP4+网页双版本）

风格验证用一次性原型已完成使命，不入正式工程。
