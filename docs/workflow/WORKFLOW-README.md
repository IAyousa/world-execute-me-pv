# 人机协作 PV 制作流水线 — 模板使用说明

> 一条**经真实成片验证**的多代理协作流水线：一名人类导演 +
> AI 代理集群，从分镜设计到逐像素验收，11 轮迭代完成一部 3.5 分钟 PV。
> 把文档中的 `{{...}}` 占位符替换成你的项目信息，即可用它制作你自己的
> 音乐视频 / 动画短片——视觉风格不必限于字符终端，任何"逐帧可渲染"
> 的风格都适用。

## 核心思想（为什么这样设计）

1. **导演只说"要什么"，代理只答"怎么画"**——中间靠一份结构化
   **分镜变更单**（YAML：`unit/window/keep/change/reject/accept_anchor/echo`）
   作为两个会话之间的唯一接口。
2. **一场景一文件** —— 每个分镜单元是独立的渲染文件，N 个实现代理
   并发而**零合并冲突**；跨段连贯性由设计会话维护的**母题账本**保证。
3. **验收锚代替审美争论** —— 每条变更必须带"带时点的验收锚"
   （如 t≈109.3 看到什么），验收 = 对锚判别式检查，不评感觉。
4. **打回路由制** —— 实现代理报"不可局部实现"时原文打回设计侧，
   编排者只附技术说明，不代替设计决策。

## 适配你自己的项目（检查单）

- [ ] **视觉契约**：写下你的硬规则（材质禁区 / 调色板 / 时间码纪律）
      ——完整范例见 [STYLE-CONTRACT.md](../STYLE-CONTRACT.md)，摘要见仓库根 `AGENTS.md`
- [ ] **时间轴单一来源**：从你的音频推导段落锚点（本项目的做法：
      MIDI 解析 + 歌词 LRC 对齐，脚本在 `scripts/`）
- [ ] **场景拆分**：一镜一文件 + 统一接口 + 调度数组（参考实现：
      `src/scenes/` + `src/FullPV.tsx`）
- [ ] **替换占位符**：全局搜索 `{{` 逐个填掉（图例见下）
- [ ] **试运行一个单元**：先走通"设计→实现→验收"单轮，再并发
