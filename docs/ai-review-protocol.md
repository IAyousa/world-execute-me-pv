# AI 复核使用规约

> 2026-10-05 从皇后字符画专案（v9–v14 蚊香事故 + 五轮定稿迭代）沉淀。
> 完整案例：`ascii-root-cause.md`。第二案例（假阴性方向，同日）：
> `STORYBOARD-DELTA-round1.md` 勘误记录。适用：任何"AI 生成 → AI/人复核 →
> 人类定稿"的视觉产出管线；大部分原则同样适用于非视觉任务。

## 0. 一句话

**每层验收只信自己能验证的东西：程序化门禁拦错误，视觉模型做判别
式复核（且问题要设计过），导演/用户只做最终验收；三层的意见冲突时，
人类的口述是唯一仲裁。**

- 人的"没问题/可以"是对**他自己所见**的裁定，不是对代理结论的确认：
  两个不相容的世界模型可以支撑同一句"不用改"（第二案例：导演看
  "大字好好的"说没问题，参谋叙事"大字缺席、黑暗克制"也记"维持现状"）。
  裁决前先复述自己的发现请人仲裁（"我测到 X，您看到的也是 X 吗？"），
  别把共鸣当确认。

## 1. 期望污染 → 用判别式提问

事故：人查与视觉模型把一只螺旋 .notdef"脑补"成皇后，模型甚至数出
了"五拱齿"——因为提示词里写明这是 queen。

- ❌ 描述性开放题（诱导脑补）："描述这个皇后字符画，五齿可数吗？"
- ✅ 判别式闭题（强迫二选一）："这是螺旋/盘绕线，还是带齿的皇后？
  说出判定依据。"
- ✅ 更进一步：不给身份的盲测——"这张图是什么？"，看完再问对照题。
- 给视觉模型看的对照图（基准 vs 产出）要同视场、同裁剪，否则它
  比较的是构图不是图形。
- **镜像也要防（第二案例，假阴性方向）**：倒数段大字为 ~0.15–0.35s
  闪现，0.5s 静帧网格屡采熄灭相位，视觉模型判"近黑无大字"（对个别
  单帧甚至判得对），被泛化成全窗"大字缺席"——把"此刻没看到"脑补成
  "不存在"。期望污染两个方向都要防：把螺旋数出五拱齿（无中生有），
  把闪现的元素判成缺席（有中变无）。对"存在性"结论，必须用 lit 帧
  反证后再下判。

## 2. 图内标注（箭头/圈划）以人口述为准

事故：导演的箭头标的是垂直拉近，视觉模型言之凿凿分析成水平方向。

- 有标注的图，先让模型**分别描述每支箭头**：起点、终点、指向的
  元素、轴向——但只当草稿，**由人确认后再执行**。
- 人的文字口述与模型对图的判读冲突时，信人的口述。图是模型的
  弱项：旋转、方向、小字、密集标注都会读错，且读错时信心不减。
- **口述反馈分两层采信（试点实测案例）**：导演对成片的口述，
  "变化存在"层面可信（他看得到你看不到的动态），"变化属性"层面
  先像素核对再作答——实测：导演称"变亮"，像素逐点对比实为 dim 雨
  密度 −33% 改变了对比结构（dim 区 ink 均值 +10%），色阶并未上调。
  口述仲裁的是"发生了变化"，不是"变化的物理成因"
  （详见 `PILOT-REPORT.md` 附录 A）。

## 3. 静默回退必须断言

事故：pala.ttf 没有 U+265B，PIL/FreeType 不报错，静默渲染 .notdef
（恰是个螺旋），六轮迭代无人察觉。

- 管线里任何"替换/回退/默认值"环节都要加**大声失败**的断言：
  - 字体缺码点：`getmask(ch).getbbox() == getmask('\uFFFF').getbbox()`
    即回退，直接 raise（`ascii_site_style.glyph_image` 有现成实现，
    另有 `--census` 普查命令可找真有该码点的字体）；
  - 依赖的 fallback 分支、配置默认值、`||` 兜底同理——先问"这里
    静默时会发生什么"，答案不能是"继续跑六轮没人发现"。

## 4. 尺寸/间距类反馈必须像素实测

事故：砍行数 -11% 后声明"已缩小"，导演看不出（感知阈值约 20%）。

- "变小/变近/变松"这类主观词，用 `audit_frame.py bbox/bands` 出
  数字：改动前后各测一次，**幅度 < 20% 视为未变**，继续加码；
- 间距用 bands 的 gap 输出定目标值，别凭感觉挪行号；
- 掩膜默认只认绿色磷光；红色 accent（meBlock）要 `--any-ink`，
  否则会误判元素缺失。
- **代理指标失效（第二案例）**：整帧墨水总量 ≠ 元素字号。单词即使
  27% 屏高，整帧墨水也仅 ~0.5%，与多字符密排组合（词卡 ~4%、整屏
  墙 ~14%）不可比。判"有没有大元素"测**元素块几何**（所在 band 内
  bbox 高度 px），不测整帧总量。
- **动态元素（闪现/呼吸/闪烁类）的存在性判定禁用低频静帧网格**：
  先 0.05s 级细扫定相位再取 lit 帧；探窗端点不得照抄手册行界截断
  （段界附近的元素会被切掉看不见）。

## 5. 分层验收链

| 层 | 拦什么 | 工具 |
|---|---|---|
| 程序化门禁 | 生成失败、密度塌陷、类型错误、尺寸没变 | 生成脚本 stdout、`audit_frame bbox/bands`、`tsc --noEmit` |
| 视觉模型判别式复核 | 形状读错、交界断裂、斑马纹、糊 | `audit_frame preview/board` 出图 + §1 的问法 |
| 导演/用户终验 | 一切主观感受 | 渲染 mp4/真帧，只在最后消耗 |

- 视觉模型复核**通过≠完成**，它只能证明"没有可指认的缺陷"；
- 前两层都过、第三层否决时，先怀疑前提（源对不对？）再改参数。

## 6. 快迭代管线（少烧渲染）

```
改 art（脚本/矢量抽屉）
  → audit_frame preview      # 秒级，同渲染度量，先看形状
  → audit_frame board        # 和基准并排，自查
  → remotion still（单帧）    # 真合成环境验证
  → 交导演 mp4（整段）        # 只在方向确认后
```

事故背景：v9–v14 每轮都渲染整段再看，往返极慢；本规约的 preview
是同 metrics 的廉价替身（Consolas advance 0.55em、line-height=fs）。
