# ADR-0015 · INTRO 第一句分镜重做：居中启动 UI（电源符号 + loading + 盾牌）

日期：2026-10-04 ｜ 状态：已实施，待导演复验
关联：ADR-0004（intro 段落重排）、ADR-0007/0012（字形剪影方法论）、ADR-0014（同日）

## 背景

导演提出：第一句 "Switch on the power line, remember to put on
PROTECTION" 意象升级——电压线改为**电源启动按键 + loading 动画**，
PROTECTION 用**盾牌**代指；并提供同人 PV（reference/fan-eodslv.mp4）
开头作参考（居中"图标|文字|进度条"启动 UI、关键时刻图标切换）；
要求图形居中、字符画"找现成的"（手绘太丑）。此前导演还质疑过
L1 歌词行位不在标准位（r25 vs r4），一并处理。

## 迭代史（半日内五版）

1. **v1 手绘字符画**（按键 5×6、砖纹块字符盾）：导演判"太丑"。
2. **v2 emoji 字形灰度**：⏻ (U+23FB, Segoe UI Emoji) 竖线被均值
   采样稀释；🛡️ 是 3/4 透视造型，alpha 剪影也歪——弃。
3. **v3 Segoe Fluent Icons 线框字形**（U+E7E8/U+EA80）：canvas 用了
   正方格比例，各向异性补偿没生效——图形只占中间 14 列，
   电源符号压扁、盾牌瘦长如灯泡。
4. **v3.1 修正画布**（按显示像素比建 canvas）：比例对了，但线框
   字形在低分辨率下断续，EA80 圆盾轮廓仍被导演判"灯泡"。
5. **v4 矢量几何实心剪影**：电源符号按 IEC 60417-5010
   几何定义绘制（粗环+顶部 ±38° 缺口+竖线），盾牌按纹章
   heater shield 绘制（平直顶边+宽肩+收尖），PIL 高分辨率实心
   → coverage 采样（gamma 0.55）。**实心剪影才是字符画正道**
   （ADR-0012 教训第三次验证）；实心填充还让逐行升起动画每行
   连续，无线框首行散架问题。图标放大到 17/16 行高。
6. **v5（定稿）导演三连修**：a) 电源符号曾整体偏右——drawArt
   以 art[0].length 锚居中而首行是空行（长度 0），改用最大行宽
   锚定；b) 盾牌按导演参考图改为**钝底盾**（平直顶边+直边+
   椭圆弧圆角收底，矩形+扁椭圆并集），弃收尖 heater shield；
   c) 十字挖空试装后被导演否决（"盾牌没有十字，不用挖空"），
   最终为纯实心。
   生成管线固化：scripts/install_intro_icons.py →
   src/scenes/intro_icons.ts（幂等）。

## 决策（定稿版式：居中启动 UI）

- **垂直层次**（全居中）：boot 日志 r2 → 歌词 r4 标准位 → 中央
  图标 r8–22 → spinner+30 格进度条 r25 → 状态行 r27。
- **时序**：0.10–0.5 电源符号呼吸（ci1↔2）；0.5 点亮闪（ci4
  0.25s）→稳态 ci3，进度条+spinner 起、状态行打字
  `booting world kernel ...`；2.92（"PROTECTION" 唱出）**中央
  图标切换**为盾牌（逐行升起 0.05s/行，升行 ci4、完成 ci3），
  状态行切 `enabling protection ...`；3.6 进度 100% + 状态行
  `[ PROTECTION: ON ]` ci4 定格至 3.87。
- 图标绘制统一色阶（形状自带密度字符），不走 densityCi——线框
  细字符在低色阶下不可读。
- 歌词 L1 移 r4 与后三句一致，根除行位不一致疑点。

## 验证

- 网格 art 直查：电源符号=粗环+竖线+顶部缺口正圆；盾牌=平顶宽
  肩收尖 heater shield。
- 四帧分镜表（intro_vec_sheet.png）+4.7s 动态预览
  （intro_vec_preview.mp4）视觉复核通过：正圆无断裂、灯泡感
  消除、尺寸醒目（约 1/3 屏高）、进度条/状态行间距协调。

v7 我误读为"皇后加在人形上方"，v8 更正——**皇后即中央主图标，

## v9 · 皇后改用标准字形源（同日续）

导演指出 v8 手绘皇后三齿会被认成车、且上半比下半大。手绘几何
弃用，改 **Palatino ♛ (U+265B) 字形**剪影（珠顶+五尖冠+项圈+
锥身+外展底座——国际象棋规范形象；探测 20 字体，仅 6 家有真
字形，Palatino 细节最全 inner-ink 43%）。glyph_drawer() 加入
生成管线（字形 alpha 覆盖采样，与矢量几何同 API）。比例自然
下大上小（底座 27 列 > 冠沿 22 列）。

## v10 · 皇后终稿：照片实心剪影（同日续）

v9 的 Palatino ♛ 是**线稿风格**字形（冠珠=小圈、冠尖=弧线、身纹
=格纹），细线在字符画上盘成"蚊香"（导演原话）——ADR-0012 教训
第三次咬人：线框不可读，必须实心。行内 flood-fill 实心化也失败
（线框冠身之间有开口，闭运算封不住，洪水灌入内部无洞可填）。
终稿走导演最初指的路——**网上现成实心剪影**：image-search 拿到
Pexels 一排黑棋白底照片（无水印 6000×4000），列投影切出 8 枚、
非引导式视觉判读识别 piece_4 为皇后；行宽剖面定位并切除镜面
倒影（y≥1300），本体 540×1300（比例 0.415=棋谱皇后）。
image_drawer() 固化（暗墨反转+coverage 采样），源图存工程资产
reference-queen-body.png。非引导式复核通过：皇后/实心/无蚊香/
下大上小（底座最宽）/居中。导演复查：15 行版冠珠仅 2 行×2-3 字符
（≈13×48px），1080p 下低于可辨认阈值——"皇冠呢"。放大到
22 行（17 列），冠珠 3 行实体+锯齿冠沿，像素与双次非引导式
复核均确认可辨；L2 布局随之重排（皇后 r7–28、打字 r31、
meBlock r34）。
（勘误：v9 复核 prompt 含"标准皇后字形"字样构成引导，未拦住
蚊香——引导式复核=走过场，教训重申。）

## v11 · 五齿皇后定稿（同日续）

导演要求"五齿皇冠"。照片剪影的冠部呈波浪感而非明确五齿，
字型线稿又不可用——直接**矢量化标准皇后几何**（draw_queen5）：
五根梯形齿（齿顶收窄）+ 冠沿带 + 收颈 + 锥身 + 最宽重底座
（0.80w 冠沿 vs 0.72w 底座，下大上小），22 行×18 列实心。
验证三层：生成 art 五齿柱分明；成片列亮度投影五个等距亮簇
（周期 39px）；非引导式视觉复核"数出五个尖齿/皇后/底最宽"。

## v12 · 皇后上 overlay 层（终稿，同日续）

导演展示了 devkitlab 字符画生成器的效果并质疑"为什么网站可以"。
根因是**分辨率约束差异**：网站画布独立（皇后 ~45 列×50 行），
而我们的皇后挤在全片 147×45 网格的图标槽里只有 18 列——五齿
每齿 2 列必然糊。解法：皇后移到 **overlay 层**（canvas 直绘，
与倒数大字卡同层的既有分层语言），8px 方格、82 行×33 列
（照片剪影 QUEEN_OVERLAY），落下动画与密度分色（@%#→main、
*+=→mid、其余 dim，落定闪 bright 0.25s）。网格层 L2 只留
歌词/构造行/meBlock（r33/r36 下移让位）。非引导式复核：
皇后五段式轮廓完整、五齿齿谷分明、"与网站生成细节水平相当"。
生成管线 render_art 参数化 cell 尺寸（网格 13×24 / overlay 8×8）。

## v13 · 皇后终稿：♛ 字形直采（同日续）

导演指出照片剪影的冠与 ♛ 差别大——要的是**符号造型**（中央
大珠+五拱齿）而非实物波浪冠。回切 Palatino ♛ 字形源：v9 蚊香
的根因是 18 列小图细线断续；v12 的 overlay 大画布（70 列×82
行、8px 格）下字形笔画 ~30px≈1 格宽，线稿天然变"粗线版♛"，
无需 solidify。aspect 0.85 忠实字形比例。非引导式复核：中央
大珠+五拱齿+弧冠沿+颈+锥身+底座全部清晰，"与 ♛ 高度相似、
无杂乱元素"。

## v14 · 蚊香终修：文本流渲染（同日续）

v13 渲染仍呈"蚊香"——根因在**渲染端**：逐字符定位、8px 格距，
但 Consolas 8px 的 advance 只有 4.4px，字符间被撕开 3.6px 空隙，
整幅画成稀疏点阵。成熟 ASCII 生成器的输出是**文本流**（等宽
字符按 advance 紧挨）。修正：整行字符串一次 fillText（分层叠色
用空格 mask 三 pass 同位叠画）；字号 14px（笔画有墨量）；生成
采样的 cell 比例同步改为 Consolas 的 8:14（0.55:1，否则横向
剪切变形）。墨密度 13.0%→16.8%；非引导式复核：笔画连续成块、
中央大珠+五拱齿可数、清晰度良好。

## v15 · 皇后专案会话终稿（2026-10-05，另会话解决）

亮度→ramp，`image_to_ascii` 按 Consolas 流 0.55 格比例采样）；
