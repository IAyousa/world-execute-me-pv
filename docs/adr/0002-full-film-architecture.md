# ADR-0002: 全曲成片架构 — 隔离工程 + 单一 FullPV 合成 + 绝对时间场景注册表

日期：2026-10-03 · 状态：已定稿（含导演中途指令修订）

## 背景

里程碑③（全曲成片）需要把 0–212 秒的完整叙事装进 Remotion。
现有四个样片各自是独立 Composition，各自 `startFrom` 偏移音频。
**导演指令（创作中途下达）**：代理生成的全部内容必须放在独立文件夹，
不得与导演既有工程（pv/、docs/、prototypes/）混放，导演后续要亲自续作。

## 决策

### 1. 隔离工程 ``

- 本文件夹自成一体：package.json / tsconfig / remotion.config / public/
  （song.json、chiptune.mp3 为副本）/ src/（引擎与 CharStage 为副本）。
- `node_modules` 为指向 `../pv/node_modules` 的**目录联接**（只读共享，
  不向导演工程写入任何字节）；渲染产物只落 `out/`。
- 导演工程 `pv/` 保持样片交付时的原样。

### 2. 单一 FullPV 合成

- 30fps / 1920×1080 / ~6360 帧；音频从 0 播整条 chiptune.mp3；
- 每个段落 = `src/scenes/Sxx*.tsx` 场景模块，导出 `draw(g, t, f)`
  （与可选 `overlay`），全部接**绝对时间 t**；
- `FullPV.tsx` 持场景注册表 `[起始秒, 场景]`，一帧只分发到当前场景；
- 样片 F1/F2/F4 的已验证逻辑按绝对时间移植进对应场景
  （Bridge←F1、Chorus2←F2、Ending←F4），不重写已验证的美术；
- 色温（官能线"升温"）按帧插值调色板：PHOSPHOR 向琥珀混合，
  PREC2 峰值 k≈0.5，其余段落回落。

段落分界沿用分镜 v2：0 / 14.8 / 29.5 / 44.3 / 58.6 / 73.9 / 81.7 /
101.5 / 132.9 / 161.0 / 175.4 / 结尾尾巴 ~211.8s。

### 3. 样片验证条款落锤（原【样片验证】项）

- 背景小号装饰伪码流：**保留**（F1/F4 已验证密度观感）
- 结尾 `// thank you, Mili` 致意卡：**保留**（F4 已验证）
- 句间交叉溶解：**保留**，以打字色阶（3→2→1）+ 上一句滞留实现
- 大字阶词卡：**保留**（F1 六语倒数 + YOUR ONLY EXECUTION 已验证）

## 影响

导演若要亲自续作：直接在 `pv/` 里继续即可，互不牵扯；
若想看代理版成果：`cd <仓库根> && npx remotion render FullPV out/FullPV.mp4`。
