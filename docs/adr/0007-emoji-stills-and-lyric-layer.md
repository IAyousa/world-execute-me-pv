# ADR-0007: emoji 静物源管线 + 歌词层置顶

日期：2026-10-03 · 状态：已定稿
触发：HANDOFF 悬置项 2/3（茄子竖直构图、番茄换 emoji 源）+ 预终审 FAIL 项。

## 茄子竖直：ROTATE_90 假设证伪

HANDOFF 记录的"转换前加 `transpose(ROTATE_90)`"在几何上不成立：🍆 emoji
呈 ~40° 对角姿态，**对角线旋转 90° 后仍是（反向）对角线**，实测产出反斜。
正确做法（`scripts/install_emoji_stills.py`）：

1. 渲染 seguiemj.ttf 彩色 emoji（PIL `embedded_color=True`）；
2. **色相分离 tone**：红/紫果体拉伸到亮端（'@' 密字符）、绿萼钉在中灰
   （'#=' 中字符）——直接 luma 会让萼比体亮（红 0.3 < 绿 0.45），与既有
   字符画视觉语言颠倒；
3. **实测主轴 deskew**（PCA）转竖直，旋转量 φ±90（PIL rotate 正角为视觉
   逆时针，与屏幕坐标 arctan2 反号）；茎端朝上由"顶部 1/4 ink 面积较小"
   自动判定；
4. 旋转后**必须再裁 ink bbox**（对角线转竖后四周出现大片透明边）。

成品 22×21；番茄走同管线免旋转，24×13（茎/双叶/星萼/密体）。
S06 迷你静物（5 行）未动。幂等：坐标 patch 用正则，可重复运行。

## 歌词层置顶（预终审 FAIL 项）

`Grid.put` 无条件覆盖 → **绘制顺序即层序**。S03Chorus1/S05Prec2 的
`typeLine` 原在 `pseudoBg`（伪代码雨）之前绘制，雨字符会插进歌词行
（62.0s 帧实录："fd" 盖 "/*"、"d|v" 入句中）。修复：歌词 `forEach` 移到
draw 末尾。S04 `antioxidants` 标签右移 4 列避让番茄右缘。

规则自此明确：**装饰层（雨/环/网格）先画，文本层（歌词/面板/标签）后画**；
新场景照此执行。
