# ADR-0003: 时间轴审计与勘误 — 间奏补齐、墙点校准、终段重排

日期：2026-10-03 · 状态：已定稿
触发：导演审片反馈"有段间奏漏掉，几段画面和音乐时长对不上"。

## 方法

不依赖记忆，直接对 ground truth 做音符级审计（`scripts/audit_timeline.mjs`、
`scripts/audit_notes.mjs`，数据源 `public/song.json` = chiptune.mp3 的母本）：
吉他和弦墙与单音线 = 主歌/副歌人声镜像；小提琴长音 = 合唱 2 后段人声镜像；
鼓组重音 = 段落边界。

## 发现与修正

### 1. 间奏（98.7–103.4s）被跳过 · 已补
小提琴末音 97.85s 结束（对应"illegal arguments"句尾），乐队（鼓+贝斯+
吉他强力和弦）直到 **103.38s** 才进入——中间 5.5s 全曲近乎静默。
DESIGN.md 本就规定此处的画面（"甜甜圈降级为间奏待机画面：无人声的世界
空转"），v1 实现因错读段落边界而跳过。
**修正**：新增 `S06bInterlude`（98.7–103.38）：异常文本余响退场 →
甜甜圈回中央待机 → `[ world.idle() — awaiting input ]` → 近黑，等墙。

### 2. Execution 墙提前 1.9s · 已校
v1 墙起于 101.5（沿用 F1 样片的 T0），但乐队齐奏点实测 **103.38s**
（103.38K+103.61S…），v1 的墙在静默里先喊了两秒。
**修正**：S07 起点改 103.38；内部相位等比压缩（墙 19.1s → 六语倒数
6×1.15s → 孤立 `;`），爆点对齐 **132.92s** 鼓重音（实测）。

### 3. 终段大错位（最大项）· 已重排
吉他人声线第三乐句实测 **162.46–191.77s**：合唱 4 之后还有约 17 秒
满编制人声叠唱。分镜 #42"OUTRO 2:57.7 起 器乐 [实]"**标注有误**
（177.7 实为叠唱中段）。v1 据此在 175.4 就开始"万物退场"，造成
16 秒强音画面对熄灭画面。
**修正**：
- 新增 `S09bReprise`（177–191.77）：副歌一式回调蒙太奇——脉冲环→
  巨型光标→完整 execute+进度条→扭曲网格→glitch 硬切。
- `S10Outro` 退场压缩进真正的器乐尾奏 **191.77–206.77**（实测仅鼓+贝斯，
  205.85–206.65 颤音琴尾音 = 最后一声 Execution）；F4 终幕原样（闪屏
  恰落 206.8 = 乐队长音切断点）。

### 4. 次级歌词/事件偏移 · 已校
- S08 大字阶词卡从爆点(133)移至其歌词位 **139.5–142.5**（#35 ≈2:20）；
- L36 打字 144→**146.5**；笼栏 152.2→**153.8**、L37 →**154.3**（#37≈2:34）；
- S09 终句 L41 →173.8、分屏画面延至 177。

### 验证过无需改的边界
14.8（吉他进入 14.77）、29.5（贝斯退）、44.3（贝斯/鼓加压）、58.6（密度谷）、
73.9（密度塌+小提琴进）、81.7、132.92（爆点重音）、159–162.5（吉他休止
3.92s = 静默小节）、206.77（末音）。

## 遗留不确定项（MIDI 无法验证，已按 [推] 处理）

S09b 叠唱歌词采用副歌一文本（4 句均分 177.2/181/184.8/188.6）。
人声内容在 MIDI 中无轨可对，须导演凭原曲核对；如实际叠唱文本不同，
只改 `S09bReprise.ts` 顶部 `L` 数组与 `T0` 即可。
