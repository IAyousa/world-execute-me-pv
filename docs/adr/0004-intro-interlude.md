# ADR-0004: 首段间奏勘误 — 吉他 riff ≠ 人声，中段段落整体重排

日期：2026-10-03 · 状态：已定稿
触发：导演二审指出——"Setup our new world"之后 0:15–0:30 是无歌词间奏，
v2 成片直接跳到了 "If I'm a set of points"。

## 根因

ADR-0003 审计沿用了分镜 v2 的假设："吉他单音线 = 人声镜像"。该假设把
14.77s 进入的吉他线当成了 VERSE 1 的人声起点（分镜 #5–8 的 [实] 即由此
而来）。实际上 0–14.8s 只有颤音琴铺底（= 开场四句人声区），14.77s 进入
的吉他是**器乐 riff**，人声直到 29.5s（贝斯撤出、颤音琴回归的织体变化点）
才随 "If I'm a set of points" 回来。旧 DESIGN v1 表的 "58.6s CHORUS"
当时反而是对的。

## 视觉处置

- **S00b（14.8–29.5）**：DESIGN 间奏条款首次完整兑现——甜甜圈居中孤转
  （世界刚诞生的第一次空转）、底部波形条把吉他 riff 显形、状态行按小节
  轮换（`users: 2 (me, you)` → `heartbeat ok` → `love.init() pending` 铺垫）。
  人声进入（29.5）即让位：甜甜圈退到 VERSE 1 的远角待机位。
- VERSE 2 静物四连改为快闪节奏（汇聚 0.5s + 短驻留）；神像站放弃
  "拉远揭示"时刻，改为 1 拍 me 字符纹理闪烁，残像交叠进 PREC 2 开场溶解。
- CHORUS 2 内部（86.9–98.5）为 [推]：vibrations 86.9 / completion 89.1 /
  YOU×5 91–94.7 / isolation 94.7 / fragments 95.9 / arguments 96.9
  （小提琴按小节一长音，无法逐句取证；如导演有原曲逐句时刻，改
  `S06Chorus2.ts` 内常量即可）。

## 教训（记入后续审计方法）

"某轨=人声镜像"的假设必须逐段验证，不能全局沿用；段落槽位错位时，
硬锚点（齐奏点/休止/密度台阶）是唯一可信的再同步基准。
