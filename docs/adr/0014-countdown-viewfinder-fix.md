# ADR-0014 · 六语倒数取景框窜位修复 + 罗马计数轨

日期：2026-10-04 ｜ 状态：已实施（含同日两次勘误）
关联：ADR-0002（F1 大字阶词卡）、ADR-0013（装饰文字分层）

## 背景

导演复核 v15 六语倒数段（158.90–161.12），指出取景框"横线竖线画反了"。

## 诊断（导演观察正确，但根因比"画反"更深）

- `Grid.put` 以浮点索引 `i = y*cols + x` 写数组。真实度量（GridProbe
  探针实测：cellW=13、**cols=147**、rows=45）下 cols 为奇数，
  `y=22.5` 行偏移的 `.5` 与 `x=73.5` 的 `.5` **相加进位成整数**——
  字符不报错也不消失，而是写入**完全错误的格子**（对角窜位 73 格）。
- S07Bridge 以 `g.cols/2`（73.5）、`g.rows/2`（22.5）浮点调 viewfinder：
  四角窜位到 (130,15)/(17,16)/(130,29)/(17,30)，┌└ 落右侧、┐┘ 落左侧，
  观感即"横竖线画反"；点线 `x%3===0` 对 *.5 永假，全部没画；
  部分角臂越界列（x≥147）彻底丢失。
- 排查教训：第一轮网格 dump 用了猜测的 cols=137 且窗口只看中央，
  窜位字符落在窗口外，一度误判为"框没画"。

## 决策

1. **引擎兜底**：`Grid.put` 对 x/y 先 `Math.round`——浮点坐标不再
   窜位（半格误差无害）。全片所有调用受益；S06/S08 原本传整数坐标，
   行为不变。
2. **取景框**：~~贴官方参考图做居中纯角括号款~~（勘误见下）→
   最终为**与 ISOLATION 段完全同款的全屏取景框**（贴边
   (6,3)→(cols-7,rows-4)、角括号+点线、arm=4）。时序：第一声
   数字后 0.08s 从中心生长 0.14s 锁定到全屏一次，后续各声框保持
   全屏、仅重新闪亮（色阶 4 半拍 → 回落 3，与 ISOLATION 持续档一致）。
3. **计数轨重构**：删除顶部六语小字历史轨（与伪代码雨混杂、不显眼），
   改为**大字下方罗马数字轨** `I II III IV V VI`——固定槽位居中
   （61–87 列，中心=cx），已数点亮、当前色阶 4、历史色阶 1，
   末声（161.58）后随段消失。选罗马而非阿拉伯/中文：碑刻仪式感与
   EXECUTION 墙同构；全大写拉丁字母与 Consolas/各语数词统一，
   无字体 fallback 风险；阿拉伯数字信息冗余。

## 勘误（同日两次）

1. **"官方参考图"系误判**：首轮修复时把导演提供的 Ein 标注图
   （用于定位窜位 bug 的截图）误当作官方 MV 参考并写入决策依据
   （"官方样式/65% 屏宽/边中段空开"），无任何依据。导演澄清该图
   非官方，并裁定**框统一为 ISOLATION 段原有的全屏款**——位置、
   大小、点线与 S06Chorus2 完全一致。
2. **锁定节奏**：若每个数字都从中心重新生长（原始意图），全屏框
   六连张合过晃；改为**第一声锁定一次**，后续声只闪亮。该"每声
   重生长"在窜位 bug 时代从未被正确看见，无导演确认史，可改。

## 验证

- 网格 dump：S07 长成态四角 ┌(6,3) ┐(140,3) └(6,41) ┘(140,41)、
  点线 104 点，与 S06 isolation 帧**逐格一致**；罗马轨 t=161.27 时
  I..VI 于 29 行、VI 最右居中收口。
- 时序 dump：t=159.0 生长中（中心小框亮4）→ 159.12 全屏降3 →
  159.4/161.27 后续声全屏保持、闪亮4。
- 上下拼图（compare_S07_S06.png）视觉复核：两段框位置/大小/点线
  完全同款；罗马轨与大字、框无冲突。

## 影响

- S07 倒数分支、`Grid.put`、`viewfinder` 签名（新增 dotted 参数，
  当前全片所有调用均传默认 true）；成片需重渲染。
- GridProbe 探针 composition 已用毕删除。
