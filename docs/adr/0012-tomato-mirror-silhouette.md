# ADR-0012: 静物专案三轮 — 番茄剪影镜像对称（右缘墙+整体右移）

日期：2026-10-04 · 状态：已定稿（导演当日确认修复生效，专案关闭）
触发：导演九审后仍说"没有完全修好"。专案新会话遵守"先问后修"：
导演锁定缺陷为**右缘/右肩不圆润，全程存在**（非动画瞬态、非标签
遮挡——那两轮已修）。

## 诊断（逐行 inset 对照，scripts/diag_tomato.py）

修版前番茄（24×13）逐行左右 inset（相对最宽行 0..23）：

- 右缘 row1–row5 连续 **5 行钉在 col22**（竖直墙），row6 才跳 col23；
  左缘同期是 `2,2,3,2,1,0` 的逐行斜坡。
- 几乎**每行 R-inset = L-inset−1**：右半边系统性多占 1 列，行中心
  12.0 vs 赤道 11.5，剪影整体右移（茎/萼也偏右）。
- 前两轮把右缘修成了"完全单调"——但**单调≠圆润**：圆润的真值是
  左右剖面一致（左缘是导演默认认可的半边），右缘是墙就仍读作
  "被削平"。量化指标没测到点上，故导演观感不变。

## 决策

- 轮廓关于中轴 col 11.5 **严格镜像**：右缘采用左缘同一阶梯
  `2,2,3,2,1,0,0,0,0,1,2,4`（底部 1,2,4 恰是 312×192px 椭圆的
  几何正确内缩）。
- 边缘字符左右**同权同密度**（row6 `*`/`*`、row9 `+`/`+`、
  row10 `%`/`%`…），消除"右缘偏稀"的密度渐变不对称（嫌疑1）。
- 茎秆行（单字符）中心 12.0 属单格限制，0.5 格偏差不可感知。
- **不越界**：不加高光、不加深底 taper、不动萼片——导演原话
  之外的"好看"改动一概不做（两轮教训：猜=白干+回退风险）。
- 全部行严格 24 列宽：convergeBitmap 按最宽行居中，行宽一致
  则放置确定、无逐行偏移。
- 未走 still_shapes.py 手绘路线：右缘问题在镜像修复后不需要
  换源（emoji 天花板嫌疑 3 未触及，留作后备）。

## 验证

- `scripts/diag_tomato.py`（新增）：字符画级（逐行 L/R inset、
  中心、偏斜行报告）+ 像素级（裁剪番茄区域逐扫描行墨迹范围）。
- 字符画级：全部行中心 11.5、左右 inset 逐行相等、偏斜行清零。
- 像素级（帧 2415 实测）：中轴两侧镜像误差 **≤2px**（字形栅格
  差异级）；右缘阶梯与左缘逐行同步（331/326/331/344/357 对
  73/76/73/59/46），5 行墙消失；标签间隙 66px≈5 列保持无回归。
- 非引导式审查（未提"右缘"字眼）："左右基本对称"，无削平报告。

## 工具链

直接编辑 `src/scenes/S04Verse2.ts` 的 TOMATO 数组（无反斜杠，
无 ADR-0010 转义风险）；row12 用 python 进程内生成精确字符串。

## 教训

- **"单调"不是"圆润"**：验收指标应是"左右剖面镜像一致"，
  而非"右缘自身单调"。
- 手写字符画行必须程序校验长度与对称（本轮手工数 `@` 连错
  两次，最终 `'%'+ '@'*12 + '%='` 程序生成一次通过）。
- 导演锁题（截图/选项+自由描述）先于任何修复——第三轮一次
  命中，前两轮各修一个量化得出但非观感所在的缺陷。
