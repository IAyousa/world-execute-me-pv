# ADR-0009: 第六轮导演五审 — 线条大猫 + 空十字

日期：2026-10-03 · 状态：已定稿
触发：导演五审两条（对第五轮 D2/D3 的修正）。

## 决策

1. **猫：回退到旧线条猫并放大**。🐈 emoji 版的胡须/斑纹在栅格化后
   糊成一团，损失了脸——"看不太清脸"。新版保留旧猫的表情基因
   （/\ 耳、o o 点眼、^ 鼻、(___) 嘴、(_) 爪垫、▒▒ 体侧阴影、═ 地板线），
   手绘放大到 28×14，与静物同级。非引导审查确认脸清晰可读
   （"two dot eyes, smiling mouth clearly readable"）。
   教训补充：**emoji 源适合"轮廓剪影"（果蔬），带表情的生物脸
   靠留白线条才可读**——线条猫与 ramp 静物混排是可接受的风格混用
   （旧版即如此），脸的可读性优先于风格统一。
2. **十字架：去掉人像，只用空十字**。导演提议，代理赞同：受难像是
   "受苦的神"，空十字是"缺席的神"——与 "you have left" 的主题共振
   更直接；且"背叛拍"把整具空十字替换为 me/e 棋盘字，"Σ me = god"
   的反讽更纯粹（神符号整个变成 me）。几何回归简单：全白拉丁十字
   26×26，梁在 28% 高度。
   ADR-0008 的"负空间人形"教训保留有效，但本轮导演选择不需要人形。
