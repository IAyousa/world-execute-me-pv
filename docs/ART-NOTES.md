# 成片字符画的来源说明（ART-NOTES）

> 一句话：**成片里的字符画没有任何"一键生成"脚本**。它是三层体系——
> 动的元素由 TS 代码逐帧现场画，静物画是开发期生成后**烤进场景文件的
> 字符串常量**，而 `scripts/ascii_art.py` 只是制作静物时用的**通用转换器**。

## 三层体系

| 层 | 内容 | 代码位置 | 来源 |
|---|---|---|---|
| ① 运行时程序化画 | 甜甜圈、心、正弦波、取景框、波形条、伪码雨、故障、EXECUTION 墙、笼/门、大字词卡 | `src/engine/deco.ts` + 各场景文件内绘制代码 | 纯数学/代码，逐帧渲染（例：甜甜圈 = donut.c 式环面公式） |
| ② 烤入的静物字符画 | 茄子、番茄、虎斑猫、皇后棋子、电源/盾牌/人形图标 | `const EGGPLANT / CAT / TOMATO / QUEEN_ICON / PWR_ICON …` 字符串数组，直接存在 `src/scenes/Sxx*.ts` 里 | 开发期一次性生成器（PIL 多边形/参数式矢量/字形渲染）产出 → 合并进场景文件。生成器本体留在开发工程，未随本仓库分发 |
| ③ 通用转换器 | `scripts/ascii_art.py`：图片/文本/内置形状 → 字符栅格 + TS 代码片段 + 终端预览 | `scripts/ascii_art.py` | 第②层静物制作时使用的工具之一（`--input` 模式）；它**不生成**成片里的任何现有素材 |

## 想改/想新增字符画？

- **改现有静物**：直接编辑场景文件里的字符串数组（如 `S04Verse2.ts` 的
  `EGGPLANT`），改完即所见即所得——数组就是素材本体，没有别的源文件。
- **做新静物**：画高分辨率底稿（PIL 多边形/参数式矢量，或一张图片）→
  `python scripts/ascii_art.py --input 底稿.png --width N` 转换 → 贴入场景
  数组。经验法则见 [STYLE-CONTRACT.md](STYLE-CONTRACT.md) 与
  [ascii-root-cause.md](ascii-root-cause.md)（实心剪影优于线框——蚊香案）。
- **做动的元素**：直接写 TS 绘制函数（参照 `deco.ts` 现有实现），不要走
  静物路线。
