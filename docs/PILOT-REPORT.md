## 4. 契约/模板卡壳点（试点核心数据）

1. **brief 旋钮建议笔误 ×1**：编排者在 VERSE1 brief 写"站4 `+0.2→-0.1`"，
   但原代码是 `ease((t - T.verse1[3] + 0.2) / 1.0)`（无内层括号，真实起点
   T−0.2=40.50），照抄会把起点**推迟**到 40.80。子代理识别表达式语义后按
   意图纠偏为 +0.5。→ 教训：brief 不该给具体替换值（DELTA 守则 2"指挥
   要什么、不指挥怎么画"同样适用于 brief 层）；编排者若给实现指引，必须
   先核对原表达式语义。
2. **测量配方盲区 ×1**：编排者指定审计字符集 `"·:0123456789ABCDEF"`
   测伪码雨——但伪码雨只画小写词首字母，该集恒 0 hits。子代理自建
   `wmyelrivstfnhpda` 专属集完成 ±33% 量化。→ 教训：编排者给的测量
   配方应先跑基线自证有效，或只给工具让子代理自定字符集并报告。
3. **帧号越界 ×1**：brief 写 f6354（=211.8s），合法帧上限 6353
   （`Math.round(211.8×30)−1`）。子代理纠偏。→ 教训：brief 帧号一律
   程序化核对。
4. **渲染范围 vs 验收锚点错位**：任务书 outro clip 范围 5738–6218 止于
   207.27s，而 U-OUTRO-r1 的锚点在 208.6s 起——导演看 clip 无法验收该
   单元（编排者以 still 补证）。→ 教训：clip 帧范围应程序化生成
