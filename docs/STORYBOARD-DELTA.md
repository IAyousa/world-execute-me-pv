# 分镜变更单（导演填写模板）

> 2026-10-05 立。基准 = `STORYBOARD-REFERENCE.md`（27 单元，LRC 逐字
> 对齐）。**本单只填要改的单元**，没提到的单元自动沿用现版成片。
> 单元 = 手册里的一个表格行/小节；时间窗照抄手册（它镜像
> `src/timeline.ts`，是唯一真值）。

## 单元模板（每单元一块，字段用 YAML 块）

```yaml
unit: INTRO-L2              # 手册单元标识（段落-句序）
window: 3.87–7.44           # 照抄手册
keep:                       # 保留的现版元素（不重做）
  - 皇后字符画主体
  - me 构造行 + meBlock
change:                     # 改什么：意图 → 元素 → 动态，导演语言即可
  - 皇后冠改小，冠宽与棋子主体直径对齐
  - 整体缩小一档，与 me 元素竖直成组（净空 ~70px 量级）
reject:                     # 负面约束——比正面描述更能防跑偏
  - 不要线稿/盘绕线感（蚊香教训）
  - 不引入位图材质
accept_anchor:              # 验收锚点：导演看什么说"过"（必填，带时间点）
  - t=6.5s：皇后/构造行/meBlock 竖直成组，冠小且与杆身齐宽
echo:                       # 跨段呼应（此单元元素在别的段重现/被回收）
  - 皇后是 chorus2 YOU×5 的第一伏笔，造型变化要向后兼容
notes: TODO(导演)           # 拿不准就留 TODO，不自行发挥
```

## 填写守则

1. **一单元一意图**：change 里每条应是同一意图的不同侧面；两个不相关
   意图 = 拆两个单元（或两轮）
2. change 写导演语言（更小/更近/更冷/更密），实现细节交给
   `STYLE-CONTRACT.md` 和代理——指挥"要什么"，不指挥"怎么画"
3. **reject 至少一条**：例如"不要再出现 X"——负面约束是防跑偏性价比
   最高的字段
4. **accept_anchor 必填且带时间点**：它同时是代理自查锚和导演验收锚，
   没有锚的单元无法门禁
5. 跨段母题（皇后/me/甜甜圈/倒数框…）必须在 `echo` 声明——
   并发实现的代理互相看不到对方，不写就不会有连贯性
6. 标注图（箭头/圈划）可以随单附上，但**必须在 notes 里用文字复述
   方向与对象**——视觉模型会读错箭头（protocol §2 惨案）

## 已验证范例：INTRO-L2 皇后五轮定稿

该单元从变更到定稿历经五轮（详见 `HANDOFF-queen-art.md`），恰好把
模板每个字段都验证了一遍。其终态参数（供代理对齐量级）：

- art：`draw_queen_piece()` 参数化 Staunton 矢量（小五齿带珠冠 ~26%
  高、领圈、内凹杆、喇叭底、环纹）→ 亮度坡道 39 行×44 列
- 渲染：overlay 文本流 FS=9、落点 yT=160；me 构造行 grid 第 24 行、
  meBlock 第 27 行；皇后底↔构造行净空 70px
- 基准帧：`out/ascii_probe/still_L2_v5_t60.png`（t=6.5s，导演定稿版）

五轮对应关系：轮1=换源（keep/change）、轮2=比例（change+anchor）、
轮3=尺寸（change+reject"不变小不算"）、轮4=渲染号（change）、
轮5=成组（change+anchor+echo）。**每轮只动一个变量**——这也是
变更单的填写哲学：一轮一单，单内一个意图。
